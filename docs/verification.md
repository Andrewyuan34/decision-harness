## 独立 Agent 实际使用

由未参与实现的 Agent，只阅读交付 Skill、引用指南，并使用命令与真实官方资料完成。它保留此前不相关的项目史上下文，因此不是清空上下文、随机分组的用户实验。主 Agent 读取了实际记录和检查结果；完整摘要见 [Agent 验证记录](agent-validation.json)。

1. **只整理标准**：给出“每周约五小时，想减少查找笔记时间”的自然语言请求。形成五条关联目标的标准，同时保留假设，没有强迫它提出候选或发起审核。[实际记录](agent-examples/a-criteria.json)
2. **调查并比较**：比较单个 JSON 文件与 SQLite，实际读取七个官方网页，形成十项判断。性能、中文搜索和恢复体验保持未知，建议包含条件与后续检查。[实际记录](agent-examples/b-initial.json)
3. **后来改变要求**：新增“桌面程序和导入程序可能同时写入且不能丢更新”。保存中间状态后，检查真实返回退出码 2，报告两项漏评、两项漏核对和旧建议失效。调查修订后保存 revision 4；检查通过，但 SQLite 是否满足完整应用要求仍为 unknown，并给出实际测试步骤。原 revision 2 可继续读取。[中间检查](agent-examples/c-changed-check.json) · [修订后的记录](agent-examples/c-revised.json)

使用中发现并修复：日期字段说明容易让人填成不带时间的日期；只整理标准时导出空章节过多。代码独立复核另发现并修复：空格修改错误刷新旧结论、复核目标字符串处理、混合证据的未知提醒，以及不存在的日历日期。相应回归测试已加入。

## 能证明和不能证明的事

已经验证的是本地工具行为、分发包和上述 Agent 使用流程。没有进行初学者用户实验，没有证明它优于普通 Agent，也没有替研究案例执行存储性能或故障恢复试验。ready 仅表示记录符合结构、覆盖与版本规则，不代表结论已经查证为真。

未验证插件商店安装界面、所有宿主兼容性或原生 PDF 渲染。没有把本地排他锁描述成抵御恶意进程的安全隔离，也没有承诺任意网络盘、硬件故障或掉电后都不会丢数据。完整 JSON 附录为复现保留，因此深入阅读版仍可能较长。
